# AI 应用与 Agent 工程参考路线

这是从原技能路线提炼的可选参考，不是用户当前计划或实际进度。采用哪些阶段、技术栈和验收要求，先根据目标与基础确认；不预设固定月份或学习评分。

建议围绕一个逐步演进的项目学习。前端可用已有 Vue/TypeScript 基础，服务端可用 Python/FastAPI，先简单存储和稳定模型 API，再按真实需要增加框架与部署能力。

| 阶段 | 主要内容 | 可观察的阶段成果 |
|---|---|---|
| Python 与后端基础 | 数据结构、函数、模块、类型、异常、JSON、HTTP、验证和 API | 独立实现小型 API，并从前端调用，能解释输入验证和错误处理 |
| LLM 应用基础 | 消息、上下文、结构化输出、流式响应、超时、成本与秘密管理 | 一个可控模型调用，能区分生成文本与经过校验的数据 |
| 手写工具循环 | 工具 schema、分派、结果关联、状态、停止条件和读写权限 | 最小可解释的工具循环，限制重复/无限调用，写入需要授权与幂等保护 |
| 检索与可靠性 | 分段、检索、引用、评估、持久状态、可观测性和失败恢复 | 带来源的知识检索与可复现评估，能定位检索和生成各自的错误 |
| MCP 与有状态流程 | 主机/客户端/服务器、工具/资源、通信、暂停与恢复 | 用标准接口暴露一个能力，为长期任务保存必要状态 |
| 交付与反馈 | 部署、说明、演示、架构、失败案例和外部反馈 | 一个能解释取舍的项目，不用框架数量代替工程成果 |

理论按需要穿插：向量/矩阵、概率、梯度、训练与验证、神经网络、token/embedding、注意力与 Transformer。优先小例子与实际问题，不把训练大模型、分布式训练或多 Agent 作为默认起点。

实际引入 API、库、SDK 或框架时再核对其当前官方资料；本次仅整理参考路线，没有安装或验证这些技术。
