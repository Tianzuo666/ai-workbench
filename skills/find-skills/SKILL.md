# 发现与安装技能

先确定具体任务、目标 AI 工具和安装范围。用户给出仓库或技能名称时读取准确来源，不用泛化搜索替代对它的介绍。

## 查找与介绍

- 优先查看已安装技能，避免重复安装同类能力。
- 可从 [skills.sh](https://skills.sh/) 或准确的上游仓库查找。已有 Skills CLI 时可用 `npx skills find <关键词>`；若 npx 会首次下载包，先取得依赖安装授权，或改用网页只读查询。
- 读取候选 SKILL.md，按需看脚本、参考资料和许可证，不仅凭名字、热度或摘要推荐。
- 说明用途、触发场景、对象、依赖、来源、权限边界和现有能力重叠，只保留相关候选。
- 没有合适技能时如实说明。一般能力足够时直接处理，不强行创建或安装技能。

## 安装

介绍或推荐不代表安装授权。用户明确要求安装时：

1. 确认来源、选定技能和用户级/项目级位置；不重复询问已给信息。
2. 检查源内容中的脚本、联网、持久写入、覆盖与状态文件，不继承他人进度。
3. 遵循目标工具支持的安装方式；有安装器时优先使用。使用 CLI 时按实际帮助确认参数，不默认全局安装或跳过交互。
4. 目标已有同名技能时说明差异，不静默覆盖。保留许可证与来源。
5. 报告实际位置、完成情况与调用方式。安装不等于已经运行、依赖验证或所有工具都能发现它。

不自动批量更新，不执行新技能中的流程；检查或运行需另有明确授权。
