# hawkeye 个人协作说明

- 本仓库是独立发布的微信小程序运营客户端，不只是产测工具；它包含设备、商品、库存、订单、运营商和平台等多个业务分包。整体结构见 `docs/architecture.md`。
- `hawkeye-southeast-asia` 是海外 Vue H5/移动端应用，`ant` 是国内 Vue H5 及生产测试微应用源码仓库。当前没有发现本小程序通过 WebView、micro-app 或 `postMessage` 直接调用这两个仓库。
- 三端会共享登录、设备详情、上传等后端接口和业务规则。修改请求参数、状态枚举、权限标识或返回数据结构时，应核对另外两个客户端是否也消费同一契约。
- 跨端页面视觉和交互不直接复制。小程序实现继续遵守仓库内的 `docs/miniprogram-ui-spec.md`，优先复用小程序现有组件、behavior 和全局样式。
- 本地开发地址放在未跟踪配置中；不得把账号、令牌、密钥或环境实际值写入文档和提交内容。
